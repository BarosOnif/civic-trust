# CivicTrust — User Flow

## Primary Journey

**FIND → UNDERSTAND → VERIFY → ACT**

### 1. Enter CivicTrust

The citizen opens the platform. Core civic-information journeys should not require an account.

### 2. Choose an Intent

The user can:
- ask a civic question;
- verify a claim;
- explore civic information;
- understand a document;
- report an issue;
- seek safety information;
- explore a community concern.

### 3. Understand the Request

The system identifies the user's intent and relevant topic.

### 4. Find Information

CivicTrust searches available civic information and source records.

### 5. Check Evidence

Relevant evidence is assessed using source type, relevance and available freshness information.

### 6. Explain

The platform presents an understandable answer or explanation.

### 7. Show Evidence

Users can inspect source organisation, title, date, supporting evidence, relevance and original source where available.

### 8. Verify Where Needed

A user can move from an answer to claim verification or submit a claim separately.

### 9. Identify the Next Step

Where possible, CivicTrust helps users identify the responsible institution, official process, reporting channel or support pathway.

### 10. Report Where Appropriate

Users can submit civic, public-service, community or relevant safety reports. The report receives a CivicTrust reference and status.

## Safety Flow

```text
Safety Concern
     ↓
Select Category
     ↓
Immediate Danger?
   /          \
 YES          NO
  ↓            ↓
Verified       Safety / Reporting
Emergency      Information
Pathway        ↓
(where         Report / Next Step
available)
```

CivicTrust must not invent emergency contacts or claim emergency-response capability.

## Community Flow

```text
Community Concern
        ↓
Understand Issue
        ↓
Find Relevant Civic Information
        ↓
Check Evidence / Context
        ↓
Identify Responsible Institution
        ↓
Take Appropriate Next Step
```

CivicTrust is not a social network or professional mediation service.

## Report Flow

```text
Report an Issue
      ↓
Select Category
      ↓
Enter Details
      ↓
Location / Evidence (optional)
      ↓
Anonymous? (where applicable)
      ↓
Submit
      ↓
CivicTrust Report ID
      ↓
Admin Review
      ↓
Status Update
```
